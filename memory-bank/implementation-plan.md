# План реализации

1. Структура проекта, memory-bank, git.
2. Голосовые команды: Stop / Are you ready? / Let's go → MP3 в `app/audio/`.
3. Плеер: выбор MP3, плейлист, следующий трек, по кругу.
4. Таймер: работа / стоп / раунды, фазы, обратный отсчёт (по реальному времени, не по тикам).
5. Приглушение музыки на паузе + голосовые команды.
6. Работа при выключенном экране: Wake Lock, Media Session, проверка на телефоне.
7. Кнопка «i» с автором, сохранение настроек.
8. Публикация (GitHub Pages) — только после разрешения.
